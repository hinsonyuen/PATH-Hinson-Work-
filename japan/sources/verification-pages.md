# Page references for checking the arms-trade data

The source is the *Annual Return of the Foreign Trade of the Empire of Japan* on HathiTrust, University of California copies ([catalog record](https://catalog.hathitrust.org/Record/100751554)).

**How to read the page numbers.** Every page number here is the **PDF page** (the page's position in the scanned file), not the number printed on the page. Each link opens HathiTrust at that position (`seq=`). If a link lands a page or two off, type the number into HathiTrust's "Jump to page" box as a sequence number. (I couldn't open HathiTrust from here to test the links, so please spot-check the first one.)

**What's in this file:**
- **1882–1884:** every row, with its page. These are the years I can see in full in the earlier session's record.
- **1885–1914:** the volume, plus the national-total pages each year was checked against. The page for each country row is in the data files on your PC (see the end of this file).
